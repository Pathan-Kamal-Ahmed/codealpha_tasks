# CodeAlpha Stock Portfolio Tracker

## Project Description
The Stock Portfolio Tracker is a beginner-friendly Python application developed as part of the CodeAlpha Python Programming Internship.

It allows users to enter stock names, quantities, and purchase prices. The program calculates the investment for each stock and the total portfolio investment.

## Features
- Add multiple stocks to a portfolio
- Calculate investment for each stock
- Calculate total investment
- Validate stock names, quantities, and prices
- Save portfolio details to a CSV file
- View saved data using spreadsheet software

## Technologies Used
- Python
- CSV module
- Lists and dictionaries
- Loops and conditional statements
- Exception handling
- File handling

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project in PyCharm.
4. Run `stock_portfolio.py`.
5. Enter the requested stock details.
6. The program generates `portfolio.csv`.

## Files
- `stock_portfolio.py` — Main Python program
- `README.md` — Project documentation
- `portfolio.csv` — Generated portfolio data

## Limitations
This project calculates investment based on the purchase price entered by the user. It does not fetch live stock prices or provide real-time profit and loss calculations.
